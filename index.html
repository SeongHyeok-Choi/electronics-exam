1과목 전기자기학

• 쿨롱의 힘: F = k · (q1·q2) / r² [N]

• 전계 E = F / q = σ / ε₀ [V/m]

• 콘덴서 에너 지: W = 1/2 C V² = Q² / (2C) [J]

• 인덕터 자기에너지: W = 1/2 L I² [J]

• 맥스웰 4방정식: ∇·D=ρ, ∇·B=0, ∇×E=-∂B/∂t, ∇×H=J+∂D/∂t

2과목 디지털응용회로

• 드모르간 법칙: (A+B)' = A'B', (AB)' = A'+B'

• XOR 논리: Y = A'B + AB' (입력이 다르면 1)

• N비트 카운터 상태 수 = 2ⁿ 개

3과목 전자회로설계

• 비반전 OP-Amp 이득: A_v = 1 + (Rf / R1)

• 반전 OP-Amp 이득: A_v = - (Rf / R1)

• 브리지 정류 직류 전압: V_dc ≒ 0.9 V_rms

• 발진 조건 (바르크하우젠): |Aβ| = 1, 위상차 0°

4과목 전자회로검증

• 10:1 프로브 실제 전압 = 읽기값 × 10

• 나이퀴스트 샘플링: f_s ≥ 2 f_max

• 리사주 정원 파형 위상차 = 90°
